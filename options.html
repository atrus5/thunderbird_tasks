Preferences for the board, the toolbar panel and reminders.

Calendar feed server

Publish calendar can send the calendar it generates to a small server running on this computer, so Thunderbird can subscribe to your board as a calendar feed.

  • What is sent: the calendar file the board generates — the title, due date and time, status, repeat rule and notes of every dated task that is not done. Nothing else; no email content.
  • Where: 127.0.0.1 (this computer) on port 8899. The add-on never contacts any other host.
  • When: only when you click Publish calendar. There are no background requests.

This stays off unless you turn it on. With it off, Publish calendar only downloads task-board.ics to your computer, and nothing is sent anywhere.
